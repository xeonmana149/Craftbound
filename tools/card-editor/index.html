Your editing loop

  1. Launch the mod once to create config/craftbound/cards.json. IntelliJ's client uses run/config/craftbound/cards.json.
  2. Open this workshop with Open Card Workshop.cmd. It loads the active file automatically. Edit a card or duplicate one to create a new card.
  3. Save, then use /craftbound cards reload in Minecraft. Cheats/operator permission is required. Finish active matches first.
  4. Use /craftbound cards give craftbound:card_id to get a card, or /craftbound cards testdeck farmer for a starter test deck and its binder.

When launched, Save overwrites the development client's active cards.json and keeps cards.json.workshop-backup.json. A standalone page in a supported browser asks you to select the existing active cards.json once; subsequent saves overwrite that selected file without an extra backup. “Save as…” can also update src/main/resources/craftbound/cards.json when you are ready to ship your balance changes.

Keep IDs stable. Existing IDs, token flags and card kinds are protected; new cards append to the binder. “Automatic text” keeps descriptions in sync with effects. Custom text changes only the wording.

The workshop keeps a recovery draft at this page's address. Export your draft before switching to another Workshop address. Save as… exports a copy; it does not update Minecraft's active file unless you explicitly replace that file.
